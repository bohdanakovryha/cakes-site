# Шар за шаром · сайт тортів на замовлення

Статичний сайт для GitHub Pages: каталог тортів із фільтром, начинки «в розрізі», кроки замовлення, Google-форма, «Про мене», відгуки, питання, контакти.

## Що редагувати

| Що | Де |
|---|---|
| Торти, ціни, фото, категорії | `script.js`, список `cakes` і `categories` |
| Начинки та кольори шарів | `script.js`, список `fillings` |
| Тексти, «Про мене», питання, контакти | `index.html` (шукайте `[…]`, `your_username`, `000`) |
| Кольори сайту | `style.css`, блок `:root` на початку |
| Фото | `images/about.jpg`, `images/cakes/…` |

Поки фото немає, на їх місці показуються акуратні заглушки.

## Google-форма

1. Створіть форму на forms.google.com. Корисні поля: ім'я, телефон, дизайн торта, начинка, вага або кількість гостей, дата й час, доставка чи самовивіз, адреса, напис на торті, посилання на референс, алергії.
2. «Відповіді» → значок Таблиць, щоб замовлення збиралися в Google Таблицю. Там же через ⋮ увімкніть сповіщення на пошту.
3. «Надіслати» → вкладка `< >` → скопіюйте адресу з `src="…"`.
4. У `index.html` замініть `https://docs.google.com/forms/d/e/ВАШ_ID_ФОРМИ/viewform?embedded=true` на своє посилання.
5. Якщо форма обрізається, збільште `height` у `style.css` (рядок `.order__form iframe`).

## Публікація на GitHub Pages

1. github.com → **+** → **New repository** → назва (наприклад `torty`), **Public** → **Create repository**.
2. **uploading an existing file** → перетягніть усі файли й папки з цієї папки (`index.html` має бути в корені) → **Commit changes**.
3. **Settings** → **Pages** → **Source: Deploy from a branch** → гілка **main**, папка **/ (root)** → **Save**.
4. За 1–2 хвилини там з'явиться адреса: `https://ваш-нік.github.io/torty/`.

Щоб оновити сайт, відредагуйте файл прямо на GitHub (✏️ → **Commit changes**). Сайт оновиться сам.
